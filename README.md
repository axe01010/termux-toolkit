## ✨ Features
- 🐧 Ubuntu/Debian proot setup
- 💻 Neovim, Tmux, Zsh pre-configured
- 🐳 Docker rootless (via podman)
- 🔧 Git, SSH, Python, Node, Go ready
- 📦 50+ CLI tools pre-installed
- 🎨 Catppuccin theme everywhere
